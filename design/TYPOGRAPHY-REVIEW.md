# 字体与版式修订

参考页面为 https://vibedev.studio/home 内实际加载的 https://vibedev.studio/vibedev-homepage/。2026-10-19 在 1440 × 960 浏览器中读取其计算样式，并核对 390px 手机布局。

参考站的中文字体栈是苹方、微软雅黑、Noto Sans SC、思源黑体及系统字体，没有单独加载中文网络字体。品牌及数字使用 Montserrat。中文标题字重 700，字距 -0.01em；功能标题在 1440px 下为 41.76px，行高 1.22；功能要点为 16.5px，行高 1.6；首屏正文为 18.72px。手机正文仍保持 16–16.5px，没有继续缩成小字。

上一版使用 Segoe UI 优先的混合字体栈，标题字重 550，字距 -0.045em，正文 13px、功能要点 12px，演示区多处 9–11px；1280px 以下继续缩小。功能区全部同侧，窗口和标题的层级不够明显。

本次将中文字体顺序调整为参考站相同的黑体栈，标题字重提升为 700，字距调整为 -0.01em。Montserrat 可变字体保存在本地，范围 400–800，文件约 38KB，字体授权及 SHA-256 记录在 font-manifest.json，访问官网时无需连接外部字体服务。

| 文字用途 | 上一版 | 新版 |
| --- | --- | --- |
| 首屏正文 | 桌面 15px / 手机 12–13px | 桌面 19px / 手机 16px |
| 功能标题 | 字重 550；1280px 时 32px | 字重 700；1440px 时约 44px，1280px 时 38px，手机 32px |
| 功能正文与要点 | 12–13px | 桌面 16–18px，手机 16px |
| Agent 演示步骤 | 11px | 桌面、手机 14px |
| 医学研究面板 | 多处 8–11px | 正文 13–15px，场景标题 25–28px |
| 导航 | 10–12px | 桌面 15px，展开菜单 17px |
| 说明与辅助文字 | 多处 8–10px | 主要说明 12–14px |

功能区新增“五种核心能力”引导，章节数字与英文分类形成独立层级，标题、描述、要点和文档入口使用一致节奏。虚拟基因敲除、文献复现两章改为窗口在左、文字在右，其余章节相反。窗口使用浅一层的标题栏、原始品牌图标、圆角边框和青色光晕；要点采用青色发光菱形。

1200px 以上且高度至少 780px 时保留滚动切章；较窄、较矮屏幕采用纵向布局，给大字号留出完整空间。手机面板调整为单列、横向页签和更高的幻灯片区域，避免将内容整体缩小。保留原始图标、科研能力顺序、双语与 EXE 直接下载。

验收脚本会检查正文和要点至少 16px、Agent 步骤至少 14px、标题字重至少 700、本地字体加载、交错构图，以及固定舞台中的内容不会覆盖导航和章节按钮。截图及结果在 artifacts/verification/。
